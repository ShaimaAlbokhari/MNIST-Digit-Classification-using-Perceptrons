# 🔢 MNIST Digit Classification using Perceptrons

A handwritten digit classification project using **ten binary Perceptrons implemented from scratch** and trained on the MNIST dataset using a **One-vs-All classification approach**.

The project explores the effect of different learning rates on Perceptron performance and evaluates the final multiclass model using accuracy and confusion matrices.

---

## 🎯 Project Objective

The objective of this project is to implement the Perceptron learning algorithm and use it to classify handwritten digits from **0 to 9**.

Instead of using a pre-built Perceptron classifier, the learning algorithm is implemented directly using NumPy.

To handle the ten MNIST classes, the project uses a **One-vs-All** strategy:

- One Perceptron is created for each digit.
- Each Perceptron learns to distinguish its target digit from all other digits.
- The final predicted class is selected using the Perceptron with the highest activation value.

---

## 📊 Dataset

The project uses the **MNIST handwritten digit dataset**.

Each image represents a handwritten digit from **0 to 9**.

The dataset files used by the notebook are:

```text
mnist_train.csv
mnist_test.csv
```

The first column contains the digit label, while the remaining columns contain the image pixel values.

---

## ⚙️ Data Preprocessing

Before training:

1. Labels are separated from the pixel features.
2. Pixel values are scaled from `0–255` to `0–1`.
3. A bias column of ones is added to the feature matrices.
4. Labels are converted into binary targets for each Perceptron.

For example, when training the Perceptron responsible for digit `5`:

```text
Digit 5      → 1
Other digits → 0
```

This process is repeated for all ten digits.

---

## 🧠 Perceptron Implementation

Each Perceptron is implemented from scratch and contains:

- Random weight initialization
- Forward computation
- Binary threshold prediction
- Error calculation
- Perceptron weight updates
- Training and testing accuracy evaluation

The weight update follows the Perceptron learning rule:

```text
error = target - prediction

weights = weights + learning_rate × error × input
```

---

## 🔟 One-vs-All Classification

The project creates:

```text
10 Perceptrons
```

One classifier is trained for each digit:

```text
0 vs All
1 vs All
2 vs All
...
9 vs All
```

For final multiclass prediction, each image is evaluated by all ten Perceptrons.

The digit corresponding to the highest activation value is selected as the final prediction.

---

## 🧪 Training Configuration

The models are trained for:

```text
Epochs: 50
```

Three learning rates are evaluated:

```text
0.001
0.01
0.1
```

Training data is shuffled during training before the Perceptron updates.

---

## 📈 Binary Perceptron Results

The notebook records the final average performance of the ten One-vs-All binary Perceptrons for each learning rate.

| Learning Rate | Training Accuracy | Test Accuracy |
|---:|---:|---:|
| 0.001 | 97.18% | 97.07% |
| 0.01 | 97.00% | 96.92% |
| 0.1 | 97.08% | 96.88% |

> These values represent the average binary One-vs-All Perceptron accuracies. They are not the final ten-class MNIST classification accuracy.

---

## 🎯 Final Multiclass Classification

After training the ten Perceptrons, final predictions are generated by selecting the classifier with the highest activation value.

The notebook reports:

| Metric | Accuracy |
|---|---:|
| Training Accuracy | **90.16%** |
| Test Accuracy | **89.62%** |

Therefore, the final test accuracy for the **10-class digit classification task** is:

```text
89.62%
```
